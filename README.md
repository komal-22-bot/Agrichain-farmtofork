# Agrichain-farmtofork

AgriChain is a web-based application designed to bring transparency, traceability, and efficiency to the agricultural supply chain. It helps track products from farmers to end consumers by maintaining clear status updates at every stage.

🚀 Features

📦 Real-time Order Tracking
Track product status from Awaiting Pickup → In Transit → Delivered
🔍 Transparent Supply Chain
Ensures visibility for farmers, distributors, and customers
📊 Dashboard with Filters
View and filter orders based on status and conditions
🔄 Status Standardization
Consistent backend–frontend data mapping for accurate display
⚡ Efficient Data Handling
Smooth API communication between frontend and backend

🛠️ Tech Stack

Frontend: HTML, CSS (Tailwind), JavaScript (React.js)

Backend: Python (Flask)

Database: MySQL

Other Tools: APIs, Git, Data Handling Logic, Razerpay

Farmer adds product details

Buyers browse and order the product

Traditional supply chains lack:
Transparency ❌
